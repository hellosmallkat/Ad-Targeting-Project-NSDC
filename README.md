# Overview

This repository contains my implementation of the **National Student Data Corps (NSDC) Ad Targeting Project**.

Online advertising platforms rely on predictive analytics to determine which advertisements are most likely to engage individual users. In this project, I developed machine learning models to predict whether a user would click on an advertisement based on demographic and behavioral data. Working through the complete supervised machine learning workflow, I explored data preprocessing, exploratory data analysis (EDA), feature engineering, model development, evaluation, and hyperparameter tuning.

By comparing multiple classification models and evaluating their performance using appropriate metrics, I gained practical experience applying machine learning techniques to a real-world marketing analytics problem while strengthening my understanding of predictive modeling and data-driven decision-making.

## Data Preprocessing

Before training machine learning models, the dataset required preparation to ensure reliable results.

This included:

* Handling missing values
* Preparing numerical and categorical features
* Encoding data where appropriate
* Organizing datasets for machine learning
* Splitting data into training and testing sets

Proper preprocessing is essential for improving model performance and reducing bias.
